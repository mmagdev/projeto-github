A base de tudo / 02

Seis palavras para começar a colaborar.

Cada conceito resolve uma parte do trabalho em equipe, do primeiro arquivo à versão publicada.

01 / REPOSITÓRIO

O projeto

É a casa do seu código: arquivos, histórico, documentação e as regras de colaboração ficam juntos.

02 / COMMIT

O registro

Um ponto salvo no histórico. Cada commit conta o que mudou e deixa o trabalho rastreável.

03 / BRANCH

A linha paralela

Uma cópia independente do projeto para experimentar ou construir uma funcionalidade sem interromper a principal.

04 / MERGE

A união

Quando o trabalho de uma branch é incorporado à branch principal, as duas histórias passam a caminhar juntas.

05 / PULL REQUEST

O convite

Uma proposta de mudança aberta para revisão. É onde a conversa e o feedback acontecem antes do merge.

06 / ISSUE

O combinado

Um espaço para registrar tarefas, bugs e ideias. Organização para que nada importante se perca.

Sem vergonha de perguntar / 04

As dúvidas que aparecem primeiro.

Git e GitHub são a mesma coisa?

Não. Git é o sistema de controle de versão que roda no seu computador. GitHub é uma plataforma online que hospeda repositórios Git e facilita a colaboração.

Preciso trabalhar em equipe para usar branches?

Não. Branches também ajudam no trabalho individual, pois permitem testar ideias com segurança sem alterar a versão estável do projeto.

O que torna um bom commit?

Uma mudança pequena, coerente e descrita com uma mensagem objetiva. Assim, qualquer pessoa consegue entender o que aconteceu no histórico.
