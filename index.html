Principais conceitos do Git & GitHub

Repositório (Repository)

Um repositório armazena o código-fonte, histórico de commits, branches e configurações do projeto. Pode ser público ou privado.

Commit

Um commit representa um conjunto de alterações salvas no histórico. Sempre inclua mensagens claras para descrever o que foi feito.

Branch

Branches permitem trabalhar em funcionalidades separadas sem afetar o código principal (geralmente main ou master).

Pull Request (PR)

Pull Requests são pedidos de revisão e fusão de uma branch para outra. Permitem revisão de código, comentários e integração contínua.

Issues

Issues são usados para rastrear tarefas, bugs e solicitações de melhoria. Podem ter labels, assignees e milestones.

Fork & Clone

Fork cria uma cópia do repositório em sua conta. Clone copia o repositório localmente para que você possa trabalhar no código.

Exemplo de fluxo de trabalho

  1. Clone o repositório: git clone <url-do-repo>
  2. Crie uma branch: git checkout -b minha-feature
  3. Faça alterações e commit: git add . e git commit -m "Descrição"
  4. Push da branch: git push origin minha-feature
  5. Abra um Pull Request no GitHub para revisão e discussão.
  6. Depois de aprovado, merge na branch principal e faça o deploy.
Dica: mantenha commits pequenos e mensagens descritivas; isso facilita a revisão e a volta atrás se necessário.
