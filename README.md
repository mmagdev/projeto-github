# Projeto Workshop GitHub - COTI Informática

Este repositório contém um projeto front-end (HTML, CSS e JavaScript) desenvolvido durante o workshop do GitHub realizado na COTI Informática.

## Sobre o projeto

O projeto foi criado como exercício prático durante o workshop para aprender sobre controle de versão com Git/GitHub e a construção de páginas web estáticas. Ele reúne arquivos HTML como páginas, CSS para estilos e JavaScript para comportamento (se houver scripts no repositório).

## Tecnologias usadas

- HTML — marcação das páginas
- CSS — estilos e layout
- JavaScript — interatividade e comportamento (quando aplicável)

> Observação: A análise de linguagem do repositório indica que a maior parte do código é HTML.

## Estrutura sugerida do repositório

- index.html — página principal
- /css — arquivos de estilo (ex.: styles.css)
- /js — scripts JavaScript (ex.: app.js)
- /assets — imagens e outros recursos

A estrutura exata pode variar dependendo dos arquivos adicionados durante o workshop.

## Como abrir e rodar o projeto no Visual Studio Code (VSCode)

1. Pré-requisitos
   - Instale o Visual Studio Code: https://code.visualstudio.com/
   - (Opcional, recomendado) Instale a extensão Live Server (por Ritwick Dey) no VSCode para recarregamento automático da página.

2. Clonar o repositório (opcional se já tiver o código local)
   - Pelo terminal:
     ```bash
     git clone https://github.com/mmagdev/projeto-github.git
     cd projeto-github
     ```
   - Ou baixe o ZIP no GitHub e extraia a pasta localmente.

3. Abrir o projeto no VSCode
   - No VSCode, escolha "File » Open Folder..." (ou "Abrir pasta...") e selecione a pasta do projeto.
   - Alternativamente, do terminal dentro da pasta do projeto execute `code .` para abrir o VSCode nessa pasta.

4. Abrir e visualizar a página
   - No painel do Explorador do VSCode, clique em `index.html` para abrir o arquivo.
   - Com a extensão Live Server instalada: clique com o botão direito em `index.html` e selecione "Open with Live Server". O navegador será aberto mostrando a página e atualizará automaticamente sempre que você salvar alterações.
   - Sem Live Server: abra `index.html` diretamente no navegador (arrastando o arquivo ou usando "Open File"). Note que alguns recursos (como requisições AJAX locais) podem ser bloqueados quando aberto via protocolo `file://`; nesse caso, use Live Server ou um servidor local.

5. Depuração
   - Use as Ferramentas de Desenvolvedor do navegador (geralmente F12) para inspecionar o DOM, verificar estilos e ver mensagens do console JavaScript.

6. Testes rápidos
   - Faça alterações em arquivos `.html`, `.css` ou `.js` e salve; com Live Server elas serão refletidas no navegador imediatamente.

## Contribuindo

Este é um projeto de aprendizado. Você pode contribuir das seguintes formas:

1. Faça um fork do repositório.
2. Crie uma branch com sua alteração: `git checkout -b minha-melhora`.
3. Faça commits claros e descriptivos.
4. Abra um Pull Request descrevendo suas mudanças.
